# neon_auth_oauth_provider (Resource)

Configures an OAuth provider for Neon Auth on a branch with your own OAuth app credentials. Requires `neon_auth` on the branch.

## Example Usage

```terraform
resource "neon_project" "example" {
  name      = "app"
  region_id = "aws-us-east-2"
}

resource "neon_auth" "example" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.branch.id
}

resource "neon_auth_oauth_provider" "github" {
  project_id    = neon_auth.example.project_id
  branch_id     = neon_auth.example.branch_id
  provider_id   = "github"
  client_id     = var.github_client_id
  client_secret = var.github_client_secret
}

resource "neon_auth_oauth_provider" "apple" {
  project_id    = neon_auth.example.project_id
  branch_id     = neon_auth.example.branch_id
  provider_id   = "apple"
  client_id     = var.apple_services_id
  client_secret = file("${path.module}/AuthKey.p8")
  apple_key_id  = var.apple_key_id
  apple_team_id = var.apple_team_id
}

variable "github_client_id" {
  type = string
}

variable "github_client_secret" {
  type      = string
  sensitive = true
}

variable "apple_services_id" {
  type = string
}

variable "apple_key_id" {
  type = string
}

variable "apple_team_id" {
  type = string
}
```

## Schema

### Required

- `branch_id` (String) Branch ID.
- `client_id` (String) Client ID of your OAuth app.
- `client_secret` (String, Sensitive) Client secret of your OAuth app; for `apple`, the contents of the `.p8` private key. Neon only returns it masked, so a change made outside Terraform is not detected.
- `project_id` (String) Project ID.
- `provider_id` (String) OAuth provider: `google`, `github`, `microsoft`, `vercel`, or `apple`. Neon enables `google` with shared development keys when Neon Auth is enabled; this resource replaces them with yours.

### Optional

- `apple_key_id` (String) Key ID of the Sign in with Apple private key. Required for `apple`.
- `apple_team_id` (String) Apple Developer Team ID. Required for `apple`.
- `microsoft_tenant_id` (String) Tenant that `microsoft` sign-in is restricted to. Neon cannot remove a tenant, so removing it replaces the provider.

### Read-Only

- `id` (String) `<project_id>/<branch_id>/<provider_id>`.
- `type` (String) `standard` once your credentials are set.



## Import

An OAuth provider is imported by `<project_id>/<branch_id>/<provider_id>`. Neon returns the client secret masked, so the first apply after an import sets `client_secret` from the configuration.

Import using the [import block](https://developer.hashicorp.com/terraform/language/import):

```hcl
import {
  to = neon_auth_oauth_provider.example
  id = "curly-poetry-30604233/br-snowy-mountain-a5jkb18i/github"
}
```

Import using the command `terraform import`:

```commandline
terraform import neon_auth_oauth_provider.example "curly-poetry-30604233/br-snowy-mountain-a5jkb18i/github"
```
