# neon_branch (Resource)

Project Branch. See details: https://neon.tech/docs/introduction/branching/

The computed `default` output reports the API default-branch designation.
`primary` is deprecated; use `default` instead.
When the API omits `primary` or returns JSON `null`, its Terraform value is `null`; explicit true and false remain unchanged.

## Example Usage

```terraform
resource "neon_project" "example" {
  name = "foo"
}

resource "neon_branch" "example" {
  project_id = neon_project.example.id
  name       = "bar"
}

### create a protected branch
resource "neon_branch" "example" {
  project_id = neon_project.example.id
  name       = "bar"
  protected  = "yes"
}

### create a branch off of a parent branch
resource "neon_branch" "parent" {
  project_id = neon_project.example.id
  name       = "foo"
}

resource "neon_branch" "child" {
  project_id = neon_project.example.id
  parent_id  = neon_branch.parent.id
  name       = "bar"
}
```

## Schema

### Required

- `project_id` (String) Project ID.

### Optional

- `name` (String) Branch name.
- `parent_id` (String) Parent branch ID.
- `parent_lsn` (String) Parent branch Log Sequence Number (LSN).
- `parent_timestamp` (Number) Parent branch point-in-time timestamp in Unix seconds. Zero when not provided by the API.
- `protected` (Boolean) Protected branch flag.

### Read-Only

- `default` (Boolean) Default branch flag.
- `id` (String) Branch ID.
- `logical_size` (Number) Branch logical size in bytes.
- `primary` (Boolean, Deprecated) Primary branch flag.



## Import

The Neon Branch can be imported to the terraform state by its composite identifier that consists of
`ProjectID` and `BranchID` separated by a forward slash.

Import using the [import block](https://developer.hashicorp.com/terraform/language/import):

For example:

```hcl
import {
  to = neon_branch.example
  id = "curly-poetry-30604233/br-snowy-mountain-a5jkb18i"
}
```

Import using the command `terraform import`:

```commandline
terraform import neon_branch.example "curly-poetry-30604233/br-snowy-mountain-a5jkb18i"
```
