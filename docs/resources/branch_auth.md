# neon_branch_auth (Resource)

Enables Neon-managed Better Auth on a branch/database. Neon supports one integration per branch. Destroy disables the integration and preserves the neon_auth schema and user data (delete_data=false). User/OAuth/email configuration is outside this resource's scope.

## Example Usage

```terraform
resource "neon_branch_auth" "app" {
  project_id    = neon_project.example.id
  branch_id     = neon_project.example.default_branch_id
  database_name = neon_project.example.database_name
}

output "auth" {
  value = {
    base_url = neon_branch_auth.app.base_url
    jwks_url = neon_branch_auth.app.jwks_url
  }
}
```

The resource manages only enablement of Neon-managed Better Auth. It does not manage users, trusted origins, OAuth providers or email configuration, and does not store the API's `secret_server_key`. Neon allows one integration per branch, even though the resource/import ID also identifies the database.

Project, branch or database changes require replacement. Destroy disables Auth with `delete_data=false`, retaining the database schema and user data. A different remote database or an unmanaged/non-Better-Auth provider is an error; refresh will not silently adopt it. Existing integrations must be imported.

## Schema

### Required

- `branch_id` (String) Neon branch ID. Only one Auth integration can exist per branch.
- `database_name` (String) Database used for managed Better Auth. Reference neon_database.app.name for dependency ordering.
- `project_id` (String) Neon project ID.

### Read-Only

- `auth_provider` (String) Always better_auth for integrations managed by this resource.
- `auth_provider_project_id` (String) Auth provider's integration identifier.
- `base_url` (String) Neon Auth service URL.
- `created_at` (String) Integration creation timestamp.
- `id` (String) Composite ID: <project_id>/<branch_id>/<database_name>.
- `jwks_url` (String) JWKS endpoint for verifying auth JWTs.
- `owned_by` (String) neon for a managed integration.



## Import

The database in the import ID must match the existing integration.

```shell
terraform import neon_branch_auth.app "PROJECT_ID/BRANCH_ID/app"
```
