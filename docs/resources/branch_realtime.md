# neon_branch_realtime (Resource)

Enables Neon Realtime on a branch. Deleting the resource disables Realtime and discards the branch's shared secret. Child branches inherit Realtime from their parent when they are created.

## Example Usage

```terraform
resource "neon_project" "realtime" {
  name      = "realtime-example"
  region_id = "aws-us-east-2"

  # Realtime enables logical replication on the project.
  enable_logical_replication = true
}

resource "neon_branch_realtime" "this" {
  project_id      = neon_project.realtime.id
  branch_id       = neon_project.realtime.default_branch_id
  allowed_origins = ["https://app.example.com"]
}

output "realtime_url" {
  value = neon_branch_realtime.this.invocation_url
}
```

## Logical replication

Enabling Realtime turns on logical replication for the whole project, and Neon can't turn it off again. Set
`enable_logical_replication = true` on the `neon_project` so the configuration matches the project. Setting it to `false`
replaces the project.

## Allowed origins

An empty list and `["*"]` both allow any origin. When `allowed_origins` is omitted, the branch keeps the origins it has,
including ones it inherited from its parent branch. Removing `allowed_origins` from the configuration later leaves the
current origins in place; set it to `[]` to allow any origin again.

## Schema

### Required

- `branch_id` (String) Branch ID. Changes require replacement.
- `project_id` (String) Project ID. Changes require replacement.

### Optional

- `allowed_origins` (List of String) Browser origins allowed to connect, such as `https://app.example.com`. An empty list, or `["*"]`, allows any origin. When omitted, the branch keeps its current or inherited origins.

### Read-Only

- `id` (String) Resource identity and import ID: <project_id>/<branch_id>.
- `invocation_url` (String) URL that clients connect to.

## Import

Import using `<project_id>/<branch_id>`:

```hcl
import {
  to = neon_branch_realtime.this
  id = "cool-moon-123/br-cool-moon-456"
}
```

Or use the CLI:

```commandline
terraform import neon_branch_realtime.this "cool-moon-123/br-cool-moon-456"
```
