# neon_branch_realtime (Resource)

Manages Realtime on a Neon branch. Destroy disables Realtime on the branch and discards its secret.

## Example Usage

```terraform
resource "neon_project" "x" {
  name = "realtime-example"
}

resource "neon_branch_realtime" "this" {
  project_id      = neon_project.x.id
  branch_id       = neon_project.x.branch.id
  allowed_origins = ["https://app.example.com"]
  # For any other branch, substitute neon_branch.example.id above.
  # Omit allowed_origins to preserve current/inherited policy without managing it.
  # [] and ["*"] both explicitly allow any origin.
}
```

Use `neon_project.x.branch.id` for the default branch, or `neon_branch.example.id` for any other branch.
A child branch inherits Realtime from a parent that has it enabled.
If Realtime is already enabled on the branch, this resource adopts it and applies the configured origins.

## Allowed origins

- Leave `allowed_origins` unset to keep the branch's current policy. Terraform does not manage origins in that case, including after import.
- Set `[]` or `["*"]` to allow any origin. Both mean the same thing and do not cause a diff.
- Set a list of origins to restrict access. Changes made outside Terraform show up as drift.
- Remove `allowed_origins` from the configuration to stop managing origins. The current policy stays in place.

## Lifecycle

- Create and update wait up to five minutes for Realtime to finish provisioning.
- Destroy disables Realtime on the branch and discards its secret, even when this resource adopted an existing setup.
- If Realtime is disabled outside Terraform, the next plan enables it again.
- Use the ephemeral `neon_branch_realtime_secret` resource to read the secret.

## Schema

### Required

- `branch_id` (String) The Neon branch ID. Changes require replacement.
- `project_id` (String) The Neon project ID. Changes require replacement.

### Optional

- `allowed_origins` (List of String) Browser origins to manage. Omitted or null preserves the current or inherited policy and leaves origins unmanaged. An explicit empty list or ["*"] allows any origin. The API validates origin syntax.

### Read-Only

- `id` (String) Resource identity and import ID: <project_id>/<branch_id>.
- `invocation_url` (String) Application Realtime endpoint, or null when not returned by the API.
- `revision` (Number) Observed Realtime configuration revision, or null when not returned by the API.

## Import

Import with `<project_id>/<branch_id>`. Origins stay unmanaged until you configure `allowed_origins`.

```hcl
import {
  to = neon_branch_realtime.this
  id = "project-id/branch-id"
}
```

```shell
terraform import neon_branch_realtime.this 'project-id/branch-id'
```
