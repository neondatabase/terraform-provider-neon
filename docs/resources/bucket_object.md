# neon_bucket_object (Resource)

Manages an object in a Neon branchable object storage bucket.

## Example Usage

```terraform
resource "neon_project" "example" {
  name      = "foo"
  region_id = "aws-us-east-2"
}

resource "neon_bucket" "example" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.branch.id
  name       = "foo"
}

resource "neon_bucket_object" "from_content" {
  project_id   = neon_bucket.example.project_id
  branch_id    = neon_bucket.example.branch_id
  bucket       = neon_bucket.example.name
  key          = "hello.txt"
  content      = "Hello, World!"
  content_type = "text/plain"
}

resource "neon_bucket_object" "from_content_base64" {
  project_id     = neon_bucket.example.project_id
  branch_id      = neon_bucket.example.branch_id
  bucket         = neon_bucket.example.name
  key            = "hello_base64.txt"
  content_base64 = base64encode("Hello, World!")
}

resource "neon_bucket_object" "from_file" {
  project_id = neon_bucket.example.project_id
  branch_id  = neon_bucket.example.branch_id
  bucket     = neon_bucket.example.name
  key        = "object"
  source     = "/path/to/file"
}

# use the data source to update the object's content in the bucket
# by tracking it using the source and its md5 hashsum as a trigger
data "local_file" "source" {
  filename = "/path/to/file/foo.bar"
}

resource "neon_bucket_object" "example" {
  project_id = neon_bucket.example.project_id
  branch_id  = neon_bucket.example.branch_id
  bucket     = neon_bucket.example.name
  key        = "object"
  source     = data.local_file.source.filename
  trigger    = data.local_file.source.content_md5
}

# provision a prefix, a/k/a folder by setting the attr. is_directory to true
resource "neon_bucket_object" "example" {
  project_id   = neon_bucket.example.project_id
  branch_id    = neon_bucket.example.branch_id
  bucket       = neon_bucket.example.name
  key          = "folder"
  is_directory = true
}
```

## Schema

### Required

- `branch_id` (String) The Neon branch ID
- `bucket` (String) The Neon object storage bucket name
- `key` (String) The object key.
- `project_id` (String) The Neon project ID

### Optional

- `content` (String, Sensitive) The content of the object. 
Note that the value is stored in the Terraform plan and state; use "source" to keep file contents out of them.
It **conflicts** with "content_base64", "source".
- `content_base64` (String, Sensitive) The base64-encoded content of the object. 
Note that the value is stored in the Terraform plan and state; use "source" to keep file contents out of them.
It **conflicts** with "content" and "source".
- `content_type` (String) The MIME type of the object.
- `is_directory` (Boolean) Set to true to provision a "folder". Note that it **conflicts** with "content", "content_base64", "source".
- `source` (String) The absolute path to the the object's content.
It **conflicts** with "content" and "content_base64".
- `trigger` (String) The provider-computed md5 check sum of the object, or user-provided string 
that is used as a trigger to re-upload the object.

### Read-Only

- `content_length` (Number) The object size in bytes.
- `etag` (String) The object's entity tag (content hash).
- `id` (String) Object state ID: <project_id>/<branch_id>/<bucket>/<key>.



## Import

The Neon Bucket Object can be imported to the terraform state by its composite identifier that consists of
`ProjectID`, `BranchID`, `BucketName` and the `Key` separated by a forward slash.

Import using the [import block](https://developer.hashicorp.com/terraform/language/import):

For example:

```hcl
import {
  to = neon_bucket_object.example
  id = "curly-poetry-30604233/br-snowy-mountain-a5jkb18i/my-bucket/my-object"
}
```

Import using the command `terraform import`:

```commandline
terraform import neon_bucket_object.example "curly-poetry-30604233/br-snowy-mountain-a5jkb18i/my-bucket/my-object"
```
