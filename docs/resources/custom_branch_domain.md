# neon_custom_branch_domain (Resource)

Registers a branch-scoped custom domain targeting a Neon Function. Creation returns before DNS/certificate activation, so DNS can depend on cname_target without a dependency cycle.

## Example Usage

```terraform
resource "neon_custom_branch_domain" "api" {
  project_id  = neon_function.api.project_id
  branch_id   = neon_function.api.branch_id
  domain      = "api.example.com"
  entity_type = "function"
  entity_id   = neon_function.api.slug
}

output "api_cname_target" {
  value = neon_custom_branch_domain.api.cname_target
}
```

`entity_id` is the function slug, rather than the API-returned `function_id`. Use the exact `cname_target` as the value of a DNS CNAME record. Registration does not wait for DNS or certificate activation; otherwise the DNS resource depending on this value could never be created. Read exposes domain/DNS/binding status, handles pagination, and removes missing registrations from state. All binding inputs require replacement. Supply a lowercase domain without a trailing dot.

## Schema

### Required

- `branch_id` (String) Neon branch ID.
- `domain` (String) Lowercase fully qualified custom domain, without a trailing dot. Changing the binding replaces this resource.
- `entity_id` (String) Function slug within the branch, typically neon_function.api.slug.
- `project_id` (String) Neon project ID.

### Optional

- `entity_type` (String) Target entity type. Currently function.

### Read-Only

- `binding_status` (String) Neon routing status returned by Neon.
- `cname_target` (String) Exact CNAME hostname returned by Neon. Empty if this region has no custom domain front door; never synthesized from the function URL.
- `dns_status` (String) DNS/CAA status returned by Neon.
- `id` (String) Composite ID: <project_id>/<branch_id>/<domain>.
- `status` (String) Current domain validity, commonly pending, active or error.
- `status_reason` (String) Machine-readable reason for a non-active status.



## Import

```shell
terraform import neon_custom_branch_domain.api "PROJECT_ID/BRANCH_ID/api.example.com"
```
