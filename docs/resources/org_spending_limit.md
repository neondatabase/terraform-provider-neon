# neon_org_spending_limit (Resource)

Manages an organization's monthly spending alert limit in cents.

## Prerequisites

Setting or removing the limit requires an organization admin. Reading requires organization read access.
Available on Launch and Scale plans only. The Neon API for spending limits is beta.
The limit sends email alerts at 80% and 100% and does not suspend computes.
See [spending notifications](https://neon.com/docs/introduction/spending-notifications).

```terraform
variable "neon_org_id" {
  type = string
}

resource "neon_org_spending_limit" "this" {
  org_id               = var.neon_org_id
  spending_limit_cents = 10000
}
```
