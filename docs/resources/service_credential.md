# neon_service_credential (Resource)

Manages a Neon scoped service credential.

## Example Usage

```terraform
resource "neon_project" "example" {
  name      = "foo"
  region_id = "aws-us-east-2"
}

# credential to grant read-write permission for the Neon Object Storage
resource "neon_service_credential" "storageRW" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.branch.id
  scopes     = ["storage:read", "storage:write"]
}

# credential to grant read-only permission for the Neon Object Storage
resource "neon_service_credential" "storageRO" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.branch.id
  scopes     = ["storage:read"]
}

# credential to grant invocation permission for the Neon AI Gateway
resource "neon_service_credential" "storageAIGW" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.branch.id
  scopes     = ["ai_gateway:invoke"]
}

# credential to grant invocation permission for the Neon Functions
resource "neon_service_credential" "functions" {
  project_id = neon_project.example.id
  branch_id  = neon_project.example.branch.id
  scopes     = ["functions:invoke"]
}
```

## Schema

### Required

- `branch_id` (String) The Neon branch ID.
- `project_id` (String) The Neon project ID.
- `scopes` (List of String) The capabilities granted to the credential.

### Optional

- `name` (String) A free-form customer label for the credential. It's an empty string if not set.

### Read-Only

- `api_token` (String, Sensitive) The API token for the credential.
- `created_at` (String) When the credential was created.
- `expires_at` (String) When the credential expires.
- `id` (String) The credential resource ID.
- `is_expired` (Boolean) Whether the credential has expired.
- `s3_secret_access_key` (String, Sensitive) The S3-compatible secret access key for the credential.
- `token_id` (String) The opaque credential ID.
- `token_id_short` (String) The first 12 hexadecimal characters of the credential ID.



## Import

The Neon Service Credential can be imported to the terraform state by its composite identifier that consists of
`ProjectID`, `BranchID` and the `TokenID` separated by a forward slash.

Import using the [import block](https://developer.hashicorp.com/terraform/language/import):

For example:

```hcl
import {
  to = neon_service_credential.example
  id = "curly-poetry-30604233/br-snowy-mountain-a5jkb18i/nak_live_37d44b17a2eb45cdb60b818e327cb33c"
}
```

Import using the command `terraform import`:

```commandline
terraform import neon_service_credential.example "curly-poetry-30604233/br-snowy-mountain-a5jkb18i/nak_live_37d44b17a2eb45cdb60b818e327cb33c"
```
